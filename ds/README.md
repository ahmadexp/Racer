# Racer DSi/DS port (Contributed by [@r00tman](https://github.com/r00tman))

https://github.com/user-attachments/assets/de714941-7dae-4a70-a1b5-602c82f7857b

This folder contains the Nintendo DSi/DS port for Racer that runs at 60 FPS on an actual DSi (and emulators, of course).

## Source structure

- `Makefile`: BlocksDS ARM9 ROM build entry.
- `source/main.c`: DS gameplay/render/HUD entry source.
- `Media/tracktexture_ds.png`: DS-specific downscaled track texture used by the ROM/NitroFS.

## Dependencies

- [BlocksDS](https://blocksds.skylyrac.net/) toolchain (`BLOCKSDS` environment variable or default path)

## Build

From this folder:

```sh
make
```

Optional toolchain override:

```sh
make BLOCKSDS=/path/to/blocksds/core
```

The compiled ROM is produced by the BlocksDS default ARM9 makeflow at `racer_dsi.nds`.

## Emulation Recommendation

Use [melonDS](https://melonds.kuribo64.net/) for emulation and quick iteration/testing. Maybe DSi Mode for faster performance. Noe that the emulator does only 30-50 FPS, but the real DSi runs at 60 FPS. DeSmuME somehow doesn't work well with this ROM (graphics glitches). Note that you can pull the SD card out during the game for quick updates, all assets are in-memory once done loading.

## Disclaimer

Port was mostly generated by feeding the original code and all BlocksDS examples to an AI agent and forcing it to fix bugs and optimize performance. Occassional manual debugging was needed to fix stuff that it had no idea about, forcing me to go figure out how stuff actually worked myself anyway. I'm happy to have learned a bit more on 3D programming for DS through this, and now would be much less scared to try doing such stuff by hand next time. *Something* tells me it might be much more fun and rewarding to do it myself than just spending hours waiting for AI to do it for me, regardless of potential time savings.
